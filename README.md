# Guitar Studio Suite

Je souhaite que tu m’aides à générer mon application pour la gestion de mes fiches de formation à la guitare. Le prototype est déjà créé en .tsx que je te joint. Il contient deux fenêtres principales , la première permet de gérer la bibliothèque et de classer mes morceaux et une deuxième qui me permet de travailler morceau par morceau. Regarde et analyse le code et tu comprendras. Je veux que tu me fournisses un fichier de type html que tu stockeras et qui recevra au fil du temps des mises à jours, mais je souhaiterais si possible de lier les données (photos, commentaires, lien, avis, … ) sur mon espace de stockage de mon iPad (icloud)
